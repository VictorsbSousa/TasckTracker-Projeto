# TaskTracker - Bootcamp II

## Descrição Funcional
O TaskTracker é uma aplicação de Interface de Linha de Comando (CLI) desenvolvida em Python para a gestão de tarefas, permitindo o cadastro e a listagem estruturada de atividades.

## Tecnologias Utilizadas
* Python 3
* Git & GitHub

## Como Executar
1. Certifique-se de que o Python 3 está instalado.
2. Navegue até à pasta raiz do projeto no terminal.
3. Execute o comando: `python src/main.py`
